Desktop Dock —— 液态玻璃桌面 Dock（Windows）
================================================

【安装】
双击「Desktop-Dock-Setup-1.1.0.exe」→ 选择安装位置（默认即可）→ 安装完成。
安装后会自动创建桌面和开始菜单快捷方式，并默认勾选"运行"。

【启动】
· 桌面快捷方式「Desktop Dock」
· 或开始菜单搜索 "Desktop Dock"
· 已自动配置开机自启，之后每次开机都会自动运行

【界面构成】
· 左侧九宫格按钮 —— 打开/关闭「应用启动面板」
· 中部 —— 你固定的常用应用（图标下方有圆点表示正在运行）
· 右侧分隔线右边 —— 当前正在运行的应用，实时同步

【常用操作】
· 点击九宫格 → 弹出启动面板（从 Dock 位置弹性展开）
· 启动面板内：搜索框输入即过滤；滚轮上下 或 ←/→ 方向键 翻页
· 在启动面板里右键任意应用 → 「固定到 Dock」
· 在 Dock 上右键已固定应用 → 「从 Dock 移除」
· 鼠标悬停任意图标 → 弹出名称标签（显示「已固定」或「正在运行」）
· 点击图标：
    - 固定且正在运行 → 切换到该窗口（最小化的自动还原弹出）
    - 未运行 → 启动该应用
    - 右侧运行中应用 → 切换到其窗口
· 点击面板外任意处 或 按 Esc → 收起面板
· 右键 Dock 空白处 → 重新扫描应用 / 隐藏任务栏 / 显示任务栏 / 退出

【应用列表来源】
扫描「开始菜单」中所有已安装应用（与桌面是否放图标无关），
并自动过滤掉附属项（首页、配置工具、指南、卸载程序等），
只保留应用本体。桌面快捷方式作为补充合并。

【图标】
使用 Windows 原生接口提取 256×256 高清图标。新装应用首次显示时
自动提取并缓存，之后加载零开销。

【任务栏】
Dock 设计为底部主入口，可右键 Dock 空白处随时
「隐藏 Windows 任务栏 / 显示 Windows 任务栏」。

【卸载】
设置 → 应用 → 已安装的应用 → 找到「Desktop Dock」→ 卸载。
（卸载后如需恢复任务栏：右键桌面 → 任务栏设置 → 关闭"自动隐藏任务栏"）

【小提示】
若某应用以「管理员权限」运行，普通权限的 Dock 无法跨权限切换其窗口，
这是 Windows 系统安全机制，属正常现象。
